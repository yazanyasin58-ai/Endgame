# Original photographs

Unprocessed files as supplied by the client. Nothing here is deployed — this
folder sits outside `public/`, so it is version-controlled but never served.

Keep originals here so a photograph can be re-cropped later without asking the
client for it again. The processed, web-sized derivative goes in
`public/img/`.
